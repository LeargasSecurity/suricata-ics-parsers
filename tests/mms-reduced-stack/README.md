# mms-reduced-stack

Some MMS tools and scanners carry the MMS PDU directly after the COTP DT,
without the ISO 8327 session, ISO 8823 presentation and ACSE layers that a
standard IEC 61850 stack uses.

## Purpose
- The TCP/102 probe and parser detect and decode this reduced stack: the flow
  is `app_proto: mms`, and the `initiate`, `start` and `read` PDUs decode.
- A `start` (program control) is flagged dangerous and fires the program-
  control rule, while a `read` is benign — classification works without the
  upper layers.

## PCAP
Generated by `scripts/gen-mms-reduced-stack-pcap.py` (standard library only):
a complete, well-formed TCP session carrying initiate, start and read over
COTP with no session/presentation/ACSE.
